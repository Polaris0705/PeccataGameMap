# 숲속 저택 — 설치 가이드

| 파일 | 내용 |
|---|---|
| `index.html` | 메인 앱. 로그인 후 KP 화면과 PL 화면이 나뉘어요 |
| `chat.js` | 채팅 기능 (index.html과 같은 폴더에 두세요) |
| `games.js` | 미니게임 모음 (index.html과 같은 폴더에 두세요) |
| `party.js` | 파티 게임 (index.html과 같은 폴더에 두세요) |
| `draw.js` | 그림 게임 (index.html과 같은 폴더에 두세요) |
| `config.js` | **HB님 설정 파일** (Firebase 값, KP 이메일, 푸시 키). 업데이트할 때 덮어쓰지 마세요 |
| `scheduler.html` | 기존 Peccata Scheduler에 연동 기능을 더한 버전. KP 화면 안에 들어가요 |
| `firestore.rules` | Firebase 보안 규칙 |

## 0. 먼저 데모로 확인하기 (선택)
`config.js`의 `firebase.apiKey`를 비워 두면 **데모 모드**로 열려요. 데이터는 그 브라우저 안에만 저장돼요.
- `kp1@example.com`으로 가입하면 KP, 다른 이메일로 가입하면 PL이에요.
- 탭을 두 개 열면 KP와 PL을 동시에 테스트할 수 있어요.
- 파일을 더블클릭해서 열면 스케줄러 연동이 막혀요. 아래 GitHub Pages에 올려서 열거나, 폴더에서 `python -m http.server`를 실행한 뒤 `http://localhost:8000`으로 열어 주세요.

## 1. Firebase 프로젝트 만들기 (무료 Spark 요금제)
1. https://console.firebase.google.com 에서 **프로젝트 추가**를 눌러요. Google 애널리틱스는 꺼도 돼요.
2. **빌드 › Authentication › 시작하기 › 이메일/비밀번호**를 사용 설정해요.
   같은 화면에서 **새 제공업체 추가 › Google**도 켜요. 프로젝트 공개용 이름과 지원 이메일(본인 Gmail)을 적고 저장하면 돼요.
3. **빌드 › Firestore Database › 데이터베이스 만들기**를 누르고, 위치는 `asia-northeast3 (서울)`, **프로덕션 모드**로 만들어요.
4. **Firestore › 규칙** 탭에 `firestore.rules` 내용을 **고치지 말고 그대로** 전부 붙여 넣고 **게시**를 눌러요.
5. **Firestore › 데이터** 탭에서 KP 명단 문서를 한 번만 만들어요.
   - **컬렉션 시작** → 컬렉션 ID `config` → 문서 ID `admins`
   - 필드 이름 `emails`, 유형 **array(배열)** → 값(string)으로 KP 두 분의 이메일을 **소문자로** 하나씩 추가 → 저장
   - 나중에 KP가 바뀌면 이 문서만 고치면 돼요. 규칙 파일은 다시 손댈 필요가 없어요.
6. **프로젝트 설정(⚙) › 내 앱 › 웹(</>)**으로 앱을 등록하면 `firebaseConfig` 값이 나와요.

## 2. config.js 설정
`config.js`를 채워요. (설정은 이 파일에만 있어서, 나중에 다른 파일을 새 버전으로 바꿔도 그대로 남아요.)
```js
firebase: { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." },
adminEmails: ["kp본인@gmail.com", "kp동료@gmail.com"],   // config/admins 문서와 똑같이 (데모 모드·예비용)
hoSins: { HO1:'wrath', ... }   // HO 번호와 칠죄종 짝이 다르면 수정
```

## 3. GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만들고 **zip 안의 파일을 전부** 올려요. `push-server` 폴더도 같이 올리면 6단계가 편해요.
2. **Settings › Pages › Branch: main / root › Save**를 누르면 `https://아이디.github.io/저장소이름/` 주소가 생겨요.
3. Firebase **Authentication › 설정 › 승인된 도메인**에 `아이디.github.io`를 추가해요. 이걸 빼먹으면 로그인이 안 돼요.

## 4. 첫 세션 준비
1. KP 두 분이 각자 회원가입해요. 관리자 이메일로 가입하면 자동으로 KP 화면이 열려요.
2. 스케줄러에서 HO와 NPC 이름, Day, 맵, 장소를 설정해요. 기존 JSON은 **📂 불러오기**로 가져오면 돼요.
3. PL에게 보여줄 장소는 맵/장소 탭에서 장소를 누르고 **👁 PL 공개**를 눌러요. 맵은 탭 옆 **🚫 비공개** 버튼을 눌러 공개로 바꿔요.
4. PL에게 주소를 보내요. PL은 가입한 뒤 자기 HO를 골라요. 잘못 골랐으면 KP가 **플레이어** 탭에서 바꿀 수 있어요. KP도 HO를 맡는다면 **플레이어 › KP 계정**에서 자기 HO를 고르면 PL과 똑같이 소지품·조사 예약·특전·랭킹·호출에 들어가요.

## 5. 앱으로 설치하기 (PWA)
- **갤럭시**: 크롬이나 삼성 인터넷으로 사이트를 열면 로비(KP는 플레이어 탭)의 **📲 앱으로 설치** 버튼이 떠요. 버튼이 안 보이면 메뉴(⋮) › **앱 설치** 또는 **홈 화면에 추가**를 눌러요.
- **아이패드/아이폰**: Safari로 열고 **공유 ⬆ › 홈 화면에 추가**를 눌러요. 크롬 앱에서는 안 되니 꼭 Safari로 해 주세요.
- 설치하면 주소창 없이 전체 화면으로 열려요. 로그인도 그대로 유지돼요.

## 6. 푸시 알림 (Railway)
화면이 꺼져 있어도 알림이 와요.
- **PL**: KP 호출, 예약 승인/거절, 새 물건(지급받거나 건네받았을 때), 숨은 글 공개, 채팅 @언급·귓속말
- **KP**: 새 조사 예약, 살펴보기 요청, 채팅 @언급·귓속말

### 6-1. 키 준비
1. **VAPID 키**: 아무 PC에서 `npx web-push generate-vapid-keys`를 실행하면 Public Key와 Private Key가 나와요.
2. **Firebase 서비스 계정 키**: Firebase 콘솔 › 프로젝트 설정 › **서비스 계정** › **새 비공개 키 생성**을 누르면 JSON 파일이 받아져요. ⚠️ 이 파일은 관리자 열쇠라서 GitHub에 올리면 안 돼요.

### 6-2. Railway에 올리기
1. 타코야키 박스가 있는 Railway 프로젝트에서 **+ New › GitHub Repo**를 누르고, 이 저장소를 골라요.
2. 새 서비스의 **Settings › Source › Root Directory**를 `push-server`로 바꿔요.
3. **Variables**에 아래 값을 넣어요.

| 이름 | 값 |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 서비스 계정 JSON 파일 내용 **전체** |
| `VAPID_PUBLIC_KEY` | 6-1의 Public Key |
| `VAPID_PRIVATE_KEY` | 6-1의 Private Key |
| `VAPID_SUBJECT` | `mailto:본인이메일` |
| `ADMIN_EMAILS` | KP 이메일 두 개를 쉼표로 (`a@gmail.com,b@gmail.com`) |

4. 배포가 끝나면 **Settings › Networking › Generate Domain**으로 주소를 만들어요. 그 주소를 열었을 때 `{"ok":true,...}`가 보이면 정상이에요.

### 6-3. 앱에서 켜기
1. `config.js`의 `vapidPublicKey`에 Public Key를 넣고 다시 올려요.
2. 각자 기기에서 **🔔 푸시 알림 켜기**를 눌러요. 아이패드는 홈 화면에 설치한 앱에서 눌러야 해요. 기기마다 한 번씩 켜야 해요.

### 비용
서버가 하는 일이 Firestore를 지켜보다가 알림을 보내는 것뿐이라 메모리를 100MB 안팎만 써요. Railway 요금으로 치면 대략 월 1달러 안팎이라, Hobby 플랜의 월 5달러 크레딧 안에서 타코야키 박스와 같이 돌아갈 가능성이 높아요. 정확한 사용량은 Railway의 Usage 화면에서 확인해 주세요.

## 새로 들어간 기능 (1차 업데이트)
- **프로필 메뉴**: 오른쪽 위 이름을 누르면 프로필 편집(이름, PL 사진, 내 캐릭터 초상화), 테마·글꼴, 앱·알림, (KP) 저택 설정, 로그아웃이 나와요.
- **테마·글꼴**: 프리셋 6종, 색 5가지 직접 고르기, 글꼴 8종, 글자 크기 4단계. KP가 **모두의 기본값으로 저장**하면 전원에게 적용되고, 각자 **내 테마 쓰기**로 덮어쓸 수 있어요.
- **채팅**: 탭 대신 PC에서는 오른쪽에 항상 떠 있어요(✕로 접고 오른쪽 💬 탭으로 펼침). 폰에서는 오른쪽 아래 💬 버튼으로 열어요.
- **스케줄러 + 예약**: PL의 신청이 KP 일정표에 주황 점선 칸으로 떠요. 누르면 승인/거절 창이 열려요. 전체 목록은 스케줄러 위 **📋 예약 목록**에서 봐요. PL은 일정표 모양 화면에서 칸을 눌러 신청해요.
- **이스터에그 은화**: 공개된 맵에서 장소가 아닌 배경을 누르면 숨겨진 은화를 찾을 수 있어요. 기본은 하루 3번, 한 번에 5은화예요. KP가 저택 설정에서 횟수, 은화, 사람마다 따로/모두 같은 자리, 다시 숨기기를 바꿀 수 있어요.

## 새로 들어간 기능 (2차 업데이트)
- **저택 지도가 첫 화면**이에요. 방을 누르면 그곳으로 이동하고, 아래에 그 방에서 할 수 있는 것들이 나와요.
- **세부 지도**: KP가 **⚙ 방 기능 설정**에서 방에 세부 지도를 연결하면(예: 1층의 '부엌' → '부엌' 지도), 그 방에서 🚪 버튼으로 안에 들어가요. 세부 지도에서도 배경을 누르면 이스터에그 은화를 찾을 수 있어요.
- **방별 기능**: 이름으로 기본 기능이 정해져요(정원→온실, 서재→수수께끼, 응접실→블랙잭·진실과 거짓, 부엌→티룸 타이쿤, 로비→랭킹 등). KP가 방 기능 설정에서 바꿀 수 있어요. 어느 방에도 없는 기능은 지도 아래 **그 밖의 즐길 거리**에 모여요.
- **위치 공개**: 처음 지도에 들어가면 공개 여부를 물어봐요. 동의한 사람만 지도에 토큰으로 보여요. 프로필 편집에서 바꿀 수 있어요.
- **소집**: KP는 **호출·대기열** 탭의 **📣 모두 소집**으로 장소를 정해 모두를 불러요. 호출 알림이 가고, 지도 위에 "그곳으로 이동" 안내가 떠요.
- **새 게임**: 티룸 타이쿤(업그레이드), 칠죄종의 방(7종 · 자기 죄는 보상 1.5배), 카드 짝맞추기, 타로 운세(하루 한 장), 살롱 블랙잭(여럿이), 진실과 거짓(여럿이). 혼자 하는 게임은 게임마다 하루 보상 5회까지예요.

## 파티 게임 (3차 업데이트 · 1단계)
누구나 **🎉 파티 게임**에서 방을 열 수 있어요. 기본으로 응접실에 배정되고, 방 기능 설정에서 다른 방으로 옮길 수 있어요. 방을 연 사람이 방장(👑)이 되어 시작해요.
- **✋ 눈치게임** (3명 이상): 1초 안에 같은 숫자가 겹치면 둘 다 탈락, 끝까지 못 외친 사람도 탈락. 살아남으면 +5 은화.
- **🔨 은화 경매** (2명 이상): 방장이 물건을 걸어요(내 소지품을 고르면 낙찰자에게 자동으로 넘어가요). 마지막 입찰 뒤 10초가 지나면 낙찰. 은화는 방장에게 가요(KP가 연 경매는 은화가 사라져요).
- **🤥 라이어 게임** (3명 이상): 주제 7종. 차례로 한 줄씩 설명 → 투표 → 지목된 라이어가 제시어를 맞히면 역전승. 라이어 승리 +15, 시민 승리 +8 은화.

## 그림 게임 · 은화 조정 (3차 업데이트 · 2단계)
- **🎨 그림 맞히기** (2명 이상): 차례대로 한 명이 단어 3개 중 하나를 골라 그리고, 나머지는 정답을 적어요. 빨리 맞힐수록 점수가 높고, 맞혀 준 만큼 그린 사람도 점수를 얻어요. 모두 한 번씩 그리면 끝(우승 +4, 참가 +2 은화).
- **📒 텔레스트레이션** (3명 이상): 각자 단어를 적으면 책이 옆으로 넘어가며 그림 → 글 → 그림… 마지막에 책을 한 권씩 펼쳐 봐요(참가 +3 은화). 그리기 90초, 맞히기 45초가 지나면 자동으로 넘어가요.
- **출석 보상**: 하루 첫 접속 때 10 → 12 → 14 → 16 → 18 → 20 → 30 은화. 하루라도 빠지면 1일째부터 다시 시작해요.
- **보상 조정**: 혼자 하는 게임은 게임별 하루 보상 2회, 온실 판매가·타이쿤·칠죄종·짝맞추기·타로·파티 게임 보상을 줄였어요. 이스터에그 기본값도 한 번에 3은화예요(KP 설정에서 바꿀 수 있어요).
- **효과음**: 은화, 정답/오답, 반짝임, 새 메시지 등. 오른쪽 위 이름 메뉴에서 켜고 끌 수 있어요.

## 내 방 (3차 업데이트 · 3단계)
- PL은 로그인하면 **🏠 내 방**에서 시작해요. KP도 HO가 있으면 내 방이 생겨요.
- **✏ 꾸미기**: 가구를 눌러 고른 뒤 원하는 칸을 누르거나, 끌어서 옮겨요. 보관함의 가구를 누르고 빈 칸을 누르면 놓여요. 벽 장식은 위쪽 벽에, 양탄자는 다른 가구 밑에 깔 수 있어요.
- **🛒 가구점**: 가구 15종, 벽 장식 6종, 벽지 6종, 바닥 5종. 질투 HO는 10% 할인.
- **가구 효과** (방에 놓아 두었을 때만): 책장 = 수수께끼 힌트 20% 할인 · 화분 = 온실 성장 5%씩 빨라짐(최대 3개) · 찻상 = 티룸 팁 +1 · 금고 = 출석 보상 +3(최대 2개) · 괘종시계 = 혼자 하는 게임 하루 보상 +1회 · 검은 고양이 = 이스터에그 반짝임 범위 넓어짐.
- **👀 놀러 가기**: 다른 손님의 방을 구경하고 ❤ 좋아요와 📖 방명록을 남겨요. 방명록은 쓴 사람, 방 주인, KP가 지울 수 있어요. 가구를 누르면 짧은 대사가 나와요.

## 도트 디자인 (3차 업데이트 · 4단계)
- 기본 화면이 옛날 게임 같은 **도트 스타일**로 바뀌었어요. 글꼴은 **갈무리11**(`fonts/` 폴더, SIL OFL 무료 글꼴)을 앱 안에 넣어서 인터넷 글꼴 서버 없이도 나와요.
- 창·버튼·입력칸이 계단식 픽셀 테두리로, 메뉴와 버튼의 이모지는 **12×12 도트 아이콘**으로 바뀌어요. 채팅·메모·방명록에 직접 쓴 이모지는 그대로예요.

- GitHub에 올릴 때 **`fonts` 폴더째로** 올려 주세요.

## 장소에서만 열리는 놀거리 · 글자 고치기 (3차 업데이트 · 5단계)
- **미니게임과 온실은 지도에 공개된 장소에서만** 열려요. KP가 그 기능을 넣은 방(⚙ 방 기능 설정, 또는 방 이름 키워드)이 공개되면, 플레이어가 그 방으로 가서 즐길 수 있어요.
- 아직 찾지 못한 놀거리는 「그 밖의 즐길 거리」에 🔒 ？？？로 보여요. 상점과 랭킹은 언제든 열려요. KP는 테스트를 위해 모든 놀거리를 열 수 있어요.
- **✏ 글자 고치기 (KP)**: 오른쪽 위 이름 메뉴 → 글자 고치기를 켜고 화면의 아무 글자(메뉴·버튼·안내문·게임 이름·입력칸 안내 등)나 누르면 바꿀 수 있어요. 저장하면 모든 사람 화면에 바로 적용돼요.
  - 바꿀 원래 글자는 일부만 남겨도 되고, 같은 글자가 들어간 곳은 앱 전체에서 함께 바뀌어요.
  - 편집 모드 중에는 화면을 눌러도 이동하지 않아요. 다른 화면의 글자를 고치려면 끝내기 → 이동 → 다시 켜기.
  - 「고친 목록」에서 되돌리거나, 잠깐 떴다 사라지는 안내문은 직접 적어서 바꿀 수 있어요.
  - 플레이어가 쓴 채팅·메모·방명록, 지도·방 그림 속 글자, KP 스케줄러 화면은 바뀌지 않아요.

## 진행 시간대 · 정밀해진 내 방 · 스케줄러 디자인 (3차 업데이트 · 6단계)
- **스케줄러 일정표**의 슬롯 번호(①②③…)를 누르면 「지금 진행 중」(▶)으로 정해지고, 옆의 시간대 아이콘을 누르면 아침 → 낮 → 저녁 → 밤 → (없음) 순서로 바뀌어요.
- 진행 중인 슬롯에 시간대가 정해져 있으면 모든 사람의 **앱 상단**에 「Day 1 ② · 🌙 밤」처럼 표시되고, **내 방 창문 밖 풍경**이 아침 노을·낮 하늘·저녁 노을·밤하늘로 바뀌어요. (정하지 않으면 밤 풍경)
- **내 방**이 2배 정밀한 도트로 다시 그려졌어요. 방 크기·칸·배치는 그대로예요.
- **스케줄러**가 앱의 테마·글꼴·도트 스타일을 따라가요. 스케줄러 ⚙ 설정 → 「앱 테마 따라가기」를 끄면 예전 스케줄러 색 설정을 쓸 수 있어요.

## 내려다보는 방 · 지도 토큰 · 새 티룸 타이쿤 · 도트 미니게임 (3차 업데이트 · 7단계)
- **내 방**이 위에서 내려다보는 시점(12×9칸)으로 바뀌었어요. 예전 배치는 비슷한 자리로 자동으로 옮겨지고, 자리가 겹치면 보관함에 들어가요. 새 가구: 안락의자, 벨벳 소파, 티 테이블, 큰 야자 화분, 페르시안 카펫, 벽난로, 액자 모음, 벽시계, 숲빛 초록 벽지.
- **지도 토큰**: 스케줄러에서 「지금 진행 중」인 슬롯에 배정된 장소에 각 HO의 도트 토큰이 자동으로 서요. 배정이 없으면 위치 공개에 동의한 사람만 자기가 누른 방에 서요.
- **티룸 타이쿤**: 하루 2분 영업. 찻잔 → 찻잎 → 뜨거운 물 → 게이지가 초록 칸일 때 탭 → 우유·꿀·레몬·휘핑 → 내놓기. 디저트는 진열장을 눌러 오븐에 굽고 꺼내요. 콤보·VIP 손님·별 3개 목표. 번 £로 주전자·작업대·오븐·인테리어·메뉴 연구를 업그레이드해요. 은화 보상은 별 1개당 5 + 손님 4명당 1 (최대 20).
- **칠죄종의 방·파티 게임**: 도트 아이콘과 게임 무대 그래픽이 들어갔어요.

## 정밀한 가구 · 색 바꾸기 (3차 업데이트 · 8단계)
- 방과 가구를 칸 하나 32×32 도트로 2배 정밀하게 다시 그렸어요. 칸 수(12×9)와 배치는 그대로예요.
- 가구가 약 70가지로 늘었어요. 가구점 분류: 침실 · 거실 · 고딕 · 식물 · 소품 · 칠죄종 · 창문·커튼 · 벽 장식 · 벽지(12) · 바닥(9) · 염료.

  - 꾸미기 → 가구를 고르면 「🎨 색 바꾸기」. 보관함에 있는 가구도 바꿀 수 있어요.

## 움직이는 GIF (3차 업데이트 · 15단계)
- 채팅 이미지 · 프로필/캐릭터 초상화 · 아이템 그림 · 내 방 그림 액자에 **움직이는 GIF**를 넣을 수 있어요.
- 큰 GIF는 저장 한도에 맞게 크기와 장면 수를 자동으로 줄여요 (채팅 약 560KB, 초상화 160KB, 아이콘 90KB, 아이템 300KB).
- 방 액자는 도트로 바꾼 장면을 최대 24장까지 이어서 움직여요. 지도 토큰은 첫 장면만 보여요.
- 적용: `gifkit.js`(새 파일), `chat.js`, `room.js`, `index.html`, `sw.js` 덮어쓰기 (캐시 v41).

## 스케줄러 맵 확대 · 장소 이름표 꾸미기 (3차 업데이트 · 16단계)
- 스케줄러 맵/장소 탭: ➖ 100% ➕ ⟲ 버튼, 두 손가락 벌리기, Ctrl+휠로 확대. 확대 중엔 빈 곳을 끌어서 이동해요.
- ✏ 편집 모드에서 장소 **이름표를 끌어서** 위치를 옮겨요 (장소 영역을 옮기면 이름표도 함께 따라가요).
- 장소 편집 창: **지도에 보일 글자**(엔터로 줄바꿈, 비우면 장소 이름) · **글자색** · **배경**(기본/없음/색) · 글씨 위치 처음대로.
- 이름표 설정은 PL 앱의 저택 지도에도 그대로 보여요.
- 적용: `scheduler.html`, `index.html`, `sw.js` 덮어쓰기 (캐시 v42).

## 스케줄러 맵 그림 바꾸기 (3차 업데이트 · 17단계)
- 맵/장소 탭 맵 이름 줄의 **🖼 그림 바꾸기**: 지금 맵의 그림만 새 파일로 바꿔요. 장소 영역·이름표·공개 설정·세부 지도 연결·보일 범위는 그대로예요.
- 비율이 다른 그림이면 영역은 비율 위치 그대로 옮겨져요 (✏ 편집 모드에서 확인).
- PL 앱의 저택 지도도 새 그림으로 바뀌어요.
- 적용: `scheduler.html`, `index.html`, `sw.js` 덮어쓰기 (캐시 v43).

## 은식기 닦기: 유튜브 노래 · 난이도 (3차 업데이트 · 18단계)
- PL: 노래(또는 노래 없이)와 난이도(쉬움·보통·어려움)를 골라 시작. 아래 큰 버튼 3개(PC는 A S D / ← ↓ →), PERFECT·GOOD·MISS 표시, 끝나면 S~D 등급.
- 박자가 밀려 보이면 '보정'에서 ±ms 조정 (기기마다 저장).
- KP: 🗂 데이터 관리 맨 아래 **🎵 은식기 닦기 노래**에서 유튜브 주소·BPM·첫 박·시작·길이를 넣어요.
  - 🎧 **BPM 맞추기**: 재생하며 TAP을 8번 이상 → BPM·첫 박 자동 계산 → 적용.
  - 🎧 **두드려 녹화**: 들으면서 줄 버튼을 두드려 박자를 녹화·저장 (녹화가 있으면 BPM 대신 녹화 박자를 써요).
- 퍼가기를 막아 둔 영상은 재생되지 않아요 (그럴 땐 안내가 뜨고 노래 없이 할 수 있어요).
- 적용: `rhythm.js`(새 파일), `index.html`, `sw.js` 덮어쓰기 (캐시 v44).

## 지도 장소 → HO 방 들어가기 (3차 업데이트 · 19단계)
- KP: 저택 지도 → ⚙ 방 기능 설정 → 장소마다 **🚪 HO 방**에서 HO를 골라 저장.
- 그 장소를 누르면 **🚪 ○○의 방 들어가기** 버튼이 생겨요. 누구나 구경(방명록·좋아요·금고 따기 그대로), 내 HO 방이면 내 방 꾸미기로 가요. 방 화면에 🗺 지도로 버튼.
- 적용: `index.html`, `room.js`, `sw.js` 덮어쓰기 (캐시 v45).

## 은식기 닦기: 키 설정 · 영상 배경 · 거품 (3차 업데이트 · 20단계)
- 고르는 화면의 **⌨ 키보드 키 바꾸기**: 🍴🔪🥄 버튼을 누른 뒤 원하는 키를 눌러요 (기기마다 저장, KP 녹화에도 같은 키).
- 노래를 고르면 유튜브 영상이 **얼룩이 떨어지는 판 뒤 배경**으로 나와요 (살짝 어둡게).
- 금색 판정선 밑에 출렁이는 **비누 거품**, 맞히면 그 줄에서 방울이 떠올라 톡 터져요.
- 적용: `rhythm.js`, `sw.js` 덮어쓰기 (캐시 v46).

## 리듬 줄 수 · 세밀 보정 · 접속 중 표시 (3차 업데이트 · 21단계)
- 은식기 닦기: **줄 수 3·4·5줄** 선택 (줄마다 키 따로, 기본 3줄 A S D / 4줄 D F J K / 5줄 D F Space J K). 녹화 박자는 4·5줄에 알아서 펼쳐요.
- **🎚 박자 보정**: −300~+300ms 슬라이더, ±1·±10 버튼, **🎯 자동 보정**(똑딱 16번에 맞춰 두드리면 자동 설정).
- **접속 중 표시**: 화면 위 🟢 n명(누르면 목록·마지막 접속), 채팅 머리에 참여자 초록 점·메시지 이름 옆 점, KP 플레이어 표에 접속 칸, 지도 토큰은 접속 중이면 초록 점·아니면 흐리게.
  - 1분마다 접속 신호를 보내고, 앱을 닫거나 다른 앱으로 가면 바로 '자리 비움'이 돼요.
- 적용: `rhythm.js`, `index.html`, `chat.js`, `sw.js` 덮어쓰기 (캐시 v47).

## 예약 고치기 · 취소 요청 · KP 변경/취소 (3차 업데이트 · 22단계)
- PL(조사 예약 › 내 조사 일정): 승인 대기 예약은 **✏ 고치기**(시간·장소·함께 갈 사람·행동) / 취소, 승인된 예약은 **취소 요청**(이유 선택) / 요청 철회.
- KP(스케줄러 › 📋 예약 목록): **취소 요청** 칸에서 수락(일정표 칸도 지움)·거절, **승인된 예약**은 ✏ 변경(일정표도 옮김)·취소. 대기열 항목도 함께 정리돼요.
- 알림: 화면 알림 + 푸시(승인·거절·취소·변경·취소 요청·요청 거절·수정).
- 적용: `index.html`, `scheduler.html`, `sw.js` 덮어쓰기 (캐시 v48) + **`firestore.rules` 다시 게시** + 푸시 서버 `push-server/rules.js` 바꾸고 Railway 다시 배포.

## 기능 요약
- **조사 예약**: PL이 신청하고 KP가 승인하면 일정표에 자동으로 배정돼요. 이미 일정이 있거나 이탈한 캐릭터는 신청 단계에서 막혀요.
- **호출·대기열**: 승인할 때 "승인+대기열"을 누르거나 직접 추가해요. **▶ 다음 차례 호출**을 누르면 PL 화면에 알림 막대와 소리가 나고, PL이 확인하면 ✓가 떠요.
- **아이템**: KP가 아이템(이미지, 설명, 숨은 글)을 만들어 지급해요. PL은 살펴보기 요청, 건네주기, 조합을 할 수 있어요. 숨은 글은 KP가 공개하기 전에는 PL 쪽에서 볼 수 없어요.
- **메모**: PL별 개인 메모와 모두가 보는 공용 메모판이 있어요.
- **채팅** (아래 1차 업데이트 참고): RP 채널, 잡담(OOC) 채널, KP가 만드는 비밀 채널(참여 HO 지정), 1:1 귓속말을 쓸 수 있어요.
  - PL은 캐릭터(인캐)와 OOC를 골라 말하고, KP는 나레이션, OOC, NPC로 말할 수 있어요.
  - `(괄호)`와 `*별표*`로 감싼 글은 똑같이 회색으로 보여요. `@이름`으로 언급하고, `@모두`로 채널 전체를 부를 수 있어요.
  - 주사위는 `/r 2d6+1`, `/r 1d100<=65`, `/cc 65 도서관`처럼 쓰거나 🎲 버튼으로 굴려요. 판정 규칙은 `config.js`의 `cocEdition`으로 6판/7판을 바꿀 수 있어요.
  - 📷 이미지 첨부, 내 메시지 수정·삭제(메시지를 누르면 버튼이 나와요), **로그** 버튼으로 복사하거나 txt로 저장할 수 있어요.
  - KP는 채널을 **🔒 잠가서** 혼자만 발언하게 할 수 있어요. 인랑 이벤트의 밤 진행에 쓰면 돼요.
  - 귓속말은 당사자 둘만 볼 수 있어요. KP 화면에도 다른 사람들끼리의 귓속말은 나오지 않아요.
  - 메시지가 오래 쌓이면 화면에는 최근 150개만 보여요. 로그 내보내기는 전체를 가져와요.
- **미니게임**: 온실, 수수께끼, 상점은 계정에 저장돼서 기기를 바꿔도 이어서 할 수 있어요. 랭킹은 누적 은화 기준이에요.

## 참고
- `firestore.rules`가 바뀌면 Firebase 콘솔 › Firestore › 규칙에 다시 붙여 넣고 **게시**해 주세요. 채팅 규칙이 들어간 이번 버전도 다시 게시해야 해요.
- 로그인은 브라우저에 저장돼서, 로그아웃하기 전까지 자동으로 유지돼요.
- 카카오톡 같은 앱 안의 브라우저에서는 Google 로그인이 막혀 있어요. 그럴 땐 화면에 **외부 브라우저로 열기** 버튼이 떠요. 이메일 로그인은 앱 안에서도 돼요.
- 7명 세션이면 Firebase 무료 한도(하루 읽기 5만, 쓰기 2만 회, 저장 1GB) 안에서 충분히 돌아가요.
- 맵 이미지는 긴 변 1600px로 압축해서 저장해요.
- 두 KP가 **같은 순간에** 스케줄러를 고치면 나중에 저장한 쪽이 이겨요. 동시에 크게 편집할 때는 말로 맞춰 주세요.
- 백업은 스케줄러의 **💾 저장**으로 하면 돼요. JSON에 맵, 공개 여부까지 들어가요.
