# 햄카타 — 설치 · 운영 가이드

크툴루의 부름(CoC) 세션용 웹앱이에요. 조사 예약, 소지품, 채팅, 저택 지도, 내 방 꾸미기, 미니게임과 파티 게임을 한곳에서 해요.
GitHub Pages(화면) + Firebase(로그인·데이터) + Railway(푸시 알림 서버)로 돌아가요.

- 설치·처음 설정 → [1~6](#0-먼저-데모로-확인하기-선택)
- 새 버전 올리기 → [업데이트하는 법](#업데이트하는-법)
- 지금 있는 기능 → [기능 한눈에 보기](#기능-한눈에-보기)
- 예전 단계별 안내 → [CHANGELOG.md](CHANGELOG.md)

## 0. 먼저 데모로 확인하기 (선택)
`config.js`의 `firebase.apiKey`를 비워 두면 **데모 모드**로 열려요. 데이터는 그 브라우저 안에만 저장돼요.
- `kp1@example.com`으로 가입하면 KP, 다른 이메일로 가입하면 PL이에요.
- 탭을 두 개 열면 KP와 PL을 동시에 테스트할 수 있어요.
- 파일을 더블클릭해서 열면 스케줄러 연동이 막혀요. GitHub Pages에 올려서 열거나, 폴더에서 `python -m http.server`를 실행한 뒤 `http://localhost:8000`으로 열어 주세요.

## 1. Firebase 프로젝트 만들기 (무료 Spark 요금제)
1. https://console.firebase.google.com 에서 **프로젝트 추가**를 눌러요. Google 애널리틱스는 꺼도 돼요.
2. **빌드 › Authentication › 시작하기 › 이메일/비밀번호**를 사용 설정해요.
   같은 화면에서 **새 제공업체 추가 › Google**도 켜요. 프로젝트 공개용 이름과 지원 이메일(본인 Gmail)을 적고 저장하면 돼요.
3. **빌드 › Firestore Database › 데이터베이스 만들기**를 누르고, 위치는 `asia-northeast3 (서울)`, **프로덕션 모드**로 만들어요.
4. **Firestore › 규칙** 탭에 `firestore.rules` 내용을 **고치지 말고 그대로** 전부 붙여 넣고 **게시**를 눌러요.
5. **Firestore › 데이터** 탭에서 KP 명단 문서를 한 번만 만들어요.
   - **컬렉션 시작** → 컬렉션 ID `config` → 문서 ID `admins`
   - 필드 이름 `emails`, 유형 **array(배열)** → 값(string)으로 KP 이메일을 **소문자로** 하나씩 추가 → 저장
   - 나중에 KP가 바뀌면 이 문서만 고치면 돼요.
6. **프로젝트 설정(⚙) › 내 앱 › 웹(</>)**으로 앱을 등록하면 `firebaseConfig` 값이 나와요.

## 2. config.js 설정
`config.js`를 채워요. 설정은 이 파일에만 있어서, 다른 파일을 새 버전으로 바꿔도 그대로 남아요.
```js
title: "햄카타",                // 화면 왼쪽 위 제목
firebase: { apiKey: "...", authDomain: "...", projectId: "...", storageBucket: "...", messagingSenderId: "...", appId: "..." },
adminEmails: ["kp본인@gmail.com", "kp동료@gmail.com"],   // config/admins 문서와 똑같이 (데모 모드·예비용)
hoSins: { HO1:'wrath', ... },   // HO 번호와 칠죄종 짝이 다르면 수정
vapidPublicKey: "...",          // 6단계 푸시 알림 Public Key
cocEdition: 7                   // 채팅 판정 규칙 (6판/7판)
```

## 3. GitHub Pages에 올리기
1. GitHub 저장소에 파일을 **전부** 올려요 (`fonts`, `push-server` 폴더 포함).
2. **Settings › Pages › Branch: main / root › Save**를 누르면 `https://아이디.github.io/저장소이름/` 주소가 생겨요.
3. Firebase **Authentication › 설정 › 승인된 도메인**에 `아이디.github.io`를 추가해요. 이걸 빼먹으면 로그인이 안 돼요.

## 4. 첫 세션 준비
1. KP가 각자 회원가입해요. 관리자 이메일로 가입하면 자동으로 KP 화면이 열려요.
2. 스케줄러에서 HO와 NPC 이름, Day, 맵, 장소를 설정해요. 기존 JSON은 **📂 불러오기**로 가져오면 돼요.
3. PL에게 보여 줄 장소는 맵/장소 탭에서 장소를 누르고 **👁 PL 공개**, 맵은 탭 옆 **🚫 비공개** 버튼으로 공개해요.
4. PL에게 주소를 보내요. PL은 가입한 뒤 자기 HO를 골라요. 잘못 골랐으면 KP가 **🗂 데이터 관리 › 플레이어 · 랭킹**에서 바꿀 수 있어요.
   KP도 HO를 맡는다면 **🗂 데이터 관리 › KP 계정**에서 HO를 고르면 PL과 똑같이 내 방·소지품·조사 예약에 들어가요.

## 5. 앱으로 설치하기 (PWA)
- **안드로이드**: 크롬으로 사이트를 열고 내 정보의 **📲 앱으로 설치** 또는 메뉴(⋮) › **앱 설치**를 눌러요.
  '홈 화면에 추가'(바로가기)로 넣으면 알림이 크롬 이름·아이콘으로 와요. 꼭 **앱 설치**로 넣어 주세요.
- **아이패드/아이폰**: Safari로 열고 **공유 ⬆ › 홈 화면에 추가**를 눌러요. 크롬 앱에서는 안 돼요.
- 설치하면 주소창 없이 전체 화면으로 열리고, 로그인도 유지돼요.
- 앱 아이콘을 바꾸려면 `icon-192.png`(192×192), `icon-512.png`(512×512), `apple-touch-icon.png`(180×180), `icon-maskable-512.png`(안드로이드 동그라미용, 그림을 62% 크기로 가운데), `badge-96.png`(알림 막대용 흰 실루엣)를 같은 이름으로 바꿔 올리고 `sw.js`의 캐시 버전을 올려요. 아이폰은 홈 화면 아이콘을 지웠다가 다시 추가해야 바뀌어요.

## 6. 푸시 알림 (Railway)
화면이 꺼져 있어도 알림이 와요 (호출, 예약 승인/거절/변경, 새 물건, 숨은 글 공개, 채팅 @언급·귓속말, 세션 일정 등).

### 6-1. 키 준비
1. **VAPID 키**: 아무 PC에서 `npx web-push generate-vapid-keys`를 실행하면 Public Key와 Private Key가 나와요.
2. **Firebase 서비스 계정 키**: Firebase 콘솔 › 프로젝트 설정 › **서비스 계정** › **새 비공개 키 생성**을 누르면 JSON 파일이 받아져요.
   ⚠️ 이 파일과 VAPID Private Key는 관리자 열쇠라서 **GitHub에 올리면 안 돼요**. Railway 변수에만 넣어요.

### 6-2. Railway에 올리기
1. Railway 프로젝트에서 **+ New › GitHub Repo**를 누르고 이 저장소를 골라요.
2. 새 서비스의 **Settings › Source › Root Directory**를 `push-server`로 바꿔요.
3. **Variables**에 아래 값을 넣어요.

| 이름 | 값 |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | 서비스 계정 JSON 파일 내용 **전체** |
| `VAPID_PUBLIC_KEY` | 6-1의 Public Key |
| `VAPID_PRIVATE_KEY` | 6-1의 Private Key |
| `VAPID_SUBJECT` | `mailto:본인이메일` |
| `ADMIN_EMAILS` | KP 이메일을 쉼표로 (`a@gmail.com,b@gmail.com`) |

4. 배포가 끝나면 **Settings › Networking › Generate Domain**으로 주소를 만들어요. 그 주소를 열었을 때 `{"ok":true,...}`가 보이면 정상이에요.

### 6-3. 앱에서 켜기
1. `config.js`의 `vapidPublicKey`에 Public Key를 넣고 다시 올려요.
2. 각자 기기에서 **🔔 푸시 알림 켜기**를 눌러요. 아이폰·아이패드는 홈 화면에 설치한 앱에서 눌러야 해요. 기기마다 한 번씩 켜야 해요.

비용: 서버는 Firestore를 지켜보다가 알림만 보내서 메모리를 100MB 안팎만 써요. 대략 월 1달러 안팎이라 Hobby 플랜 크레딧 안에서 돌아갈 가능성이 높아요. 정확한 사용량은 Railway의 Usage 화면에서 확인해 주세요.

## 업데이트하는 법
1. 새 버전 파일을 저장소에 덮어써요. **`config.js`는 그대로** 두세요.
2. `firestore.rules`가 바뀌었으면 Firebase 콘솔 › Firestore › 규칙에 **전체를 다시 붙여 넣고 게시**해요. 안 하면 새 기능에서 "실패"가 떠요.
3. `push-server/`가 바뀌었으면 Railway에서 다시 배포해요 (GitHub와 연결돼 있으면 자동).
4. `sw.js`의 캐시 버전(`peccata-vNN`)이 올라가면 앱이 새 파일을 받아요. 바로 안 바뀌면 **새로고침을 한두 번** 해 주세요.

## 테스트 계정
PL 화면이 실제로 어떻게 보이는지 확인할 때 써요.
- **시크릿 창**(또는 다른 브라우저)에서 회원가입 → '이메일 또는 아이디'에 `test_1`처럼 **`test_`로 시작하는 아이디**와 비밀번호(6자 이상).
- HO를 고르지 않아도 바로 PL 화면으로 들어가요 (HO 이름은 '테스트').
- 다른 PL 화면의 회원 목록 · 지도 · 방 구경 · 순위에는 안 보여요. KP 화면에는 보여요.
- 아이디 계정은 비밀번호를 잊으면 찾을 수 없으니 따로 적어 두세요. 테스트 계정으로 쓴 채팅이나 연 파티 방은 PL에게 보여요.
- `@` 없이 아이디만 쓰면(속으로는 `아이디@id.hamkata.app`) 일반 PL도 아이디로 가입할 수 있어요 (`test_`가 아니면 보통 계정).

## 기능 한눈에 보기

### PL 화면
| 탭 | 내용 |
|---|---|
| 🏠 내 방 | 방 꾸미기, 가구점, 가구 효과, 다른 손님 방 구경(❤ 좋아요 · 📖 방명록) |
| 🗺 저택 지도 | 공개된 장소로 이동, 장소마다 열리는 놀거리, 세부 지도, HO 방 들어가기, 이스터에그 은화 |
| 조사 예약 | 일정표에서 칸을 골라 신청 · 고치기 · 취소 요청, 동행 신청 |
| 소지품 | KP가 준 아이템(살펴보기 요청 · 건네주기 · 조합), 📜 쪽지 |
| 메모 | 개인 메모 · 공용 메모판 |
| 📅 일정 | 세션 일정 · 참석 응답 (KP가 참가자를 고르면 일부만 모이는 일정), 일정 조율 (사람을 골라 공통 날 보기) |
| 📰 소식지 | 저택 소식지 읽기 · 기고 |
| 내 정보 | 출석 · 오늘의 미션 · 칭호 · 상점 · 랭킹 · 일기 · 선물 · 앱 설치 · 알림 |

화면 위에는 진행 중인 Day·시간대, 🟢 접속 중인 사람, 호출 알림 막대가 떠요. KP가 호출할 때 링크(세션룸 · 음악 등)를 골라 붙이면 호출 막대에 🔗 버튼이 같이 뜨고, **지금 갈게**를 누르면 첫 번째 링크가 바로 열려요. 채팅은 PC에서는 오른쪽, 폰에서는 💬 버튼으로 열어요.

### KP 화면
탭: 🧭 대시보드 · 🗝 스케줄러 · 📦 아이템 · 📝 메모 · 📅 일정 · 📰 소식지 · 🗺 저택 지도 (KP가 HO를 맡으면 🏠 내 방 · 👤 내 정보도). 온실 · 수수께끼 · 상점 · 랭킹은 PL처럼 지도 · 내 정보에서 들어가요.
- **🧭 대시보드**: 접속 · 미응답 호출 · 승인 대기 예약 · 다음 일정 한눈에. 아래에 **호출 · 대기열**(다음 차례 호출, 📣 모두 소집, 호출 답 확인).
- **🗝 스케줄러**: 일정표(진행 중 칸 ▶ · 시간대 · 자동 호출), 맵/장소(공개 · 이름표 꾸미기 · 그림 바꾸기 · 보일 범위), 📋 예약 목록(승인 · 변경 · 취소 요청 처리).
- **아이템**: 아이템 만들기 · 지급 · 숨은 글 공개.
- **오른쪽 위 메뉴**: 👤 프로필 · 🎨 테마 · 📱 앱 · 알림(효과음 포함) · ⚙ 저택 설정(이스터에그 · 🔗 호출 링크 · 방 기능 · ✏ 글자 고치기) · 🗂 데이터 관리(플레이어 · HO 배정 · KP 계정 · 🏷 HO 이름 · 은화 · 쪽지 · 칭호 · 테두리 · 백업/복원/초기화 · 은식기 닦기 노래 · 🔧 권한 진단) · 🪑 가구.

### 저택 지도 · 장소
- 공개된 장소만 보이고 여백은 자동으로 잘려요. 확대 · 이동 · 전체 화면.
- 장소마다 놀거리를 KP가 정해요(⚙ 방 기능 설정, 기본은 이름 키워드). 공개된 장소에서만 열려요.
- 스케줄러 진행 중 칸에 배정된 장소에 HO 말이 자동으로 서요.
- `{HO1}` · `{분노}`처럼 쓰면 그 HO 캐릭터 이름으로 보여요 (`{HO1:PL}`은 플레이어 닉네임).

### 내 방
- 위에서 내려다보는 12×9칸 방. 가구 약 70가지(4방향 회전 · 부분별 색 바꾸기 · 염료), 벽지 · 바닥 · 테두리 색.
- 가구 효과: 책장 · 화분 · 찻상 · 금고 · 괘종시계 · 검은 고양이 · 자물쇠 등. 칠죄종 가구는 자기 HO 가구가 무료로 놓여요.
- 액자 · 이젤에 사진 넣기(움직이는 GIF 가능), 창밖 풍경은 진행 중 시간대를 따라가요.
- 창문 3종 · 천개 침대는 눌러서 **커튼 치기**(방문자도 가능, 창문 커튼을 치면 방이 살짝 어두워짐).
- 다른 손님 방의 금고를 눌러 **자물쇠 따기**.

### 놀거리 (은화 벌기)
온실 · 티룸 타이쿤(부엌 머지 포함) · 찻잔 떨어뜨리기 · 카드 짝맞추기 · 은식기 닦기(유튜브 노래 리듬) · 서재 선반 정리 · 자물쇠 따기 · 살롱 블랙잭 · 🔮 오늘의 운세(하루 한 장, 그날 효과).
- 판 수는 무제한, 은화는 게임마다 하루 상한이 있어요(괘종시계로 늘어남). 출석 · 오늘의 미션 · 주간 랭킹.
- 은화를 벌면 확률로 **쪽지 수수께끼**가 떠요. 다 풀면 숨겨진 방이 열려요.

### 파티 게임
누구나 방을 열어요. 방장이 봇을 넣어 인원을 채울 수 있어요.
눈치게임 · 은화 경매 · 라이어 게임 · 🐺 인랑(앱이 밤 · 낮 · 투표 자동 진행) · 🎨 그림 맞히기 · 📒 텔레스트레이션.

### 채팅
- RP · 잡담(OOC) · KP 비밀 채널 · 1:1 귓속말. PL은 인캐/OOC, KP는 나레이션 · OOC · NPC로 말해요.
- `@이름` · `@모두` 언급, `/r 2d6+1` · `/cc 65 도서관` 주사위, 이미지 · GIF 첨부, 수정 · 삭제, 로그 저장, 🔒 채널 잠그기.

### 세션 밖
📅 세션 일정 · 참석 응답 · 알림, 🗓 일정 조율, 📰 저택 소식지, 📔 캐릭터 일기(보여 줄 사람 고르기), 🎁 선물하기(은화 · 가구 · 아이템), 🎖 칭호.

### 꾸미기 · 만들기
- **테마 · 글꼴**: 도트/클래식 스타일, 프리셋, 색 직접 고르기, 글자 크기. KP가 모두의 기본값을 정해요.
- **🪑 가구 (KP)**: 가구점 분류 · 숨기기, 가구 그림 바꾸기, 새 가구 만들기. PL도 정해진 수만큼 가구를 만들 수 있고, 가구 경매가 열려요.
- **도트 편집기**: 레이어 · 장면(움직임) · 장면별 시간 · 외곽선/그림자 · 팔레트 · 밑그림 · 배경색 · 반투명 점 지우기 · 새 레이어로 불러오기 · 프리셋.
- **✏ 글자 고치기 (KP, ⚙ 저택 설정 안)**: 화면의 아무 글자나 눌러 바꾸면 모두에게 적용돼요.

## 참고
- 로그인은 브라우저에 저장돼서 로그아웃하기 전까지 유지돼요.
